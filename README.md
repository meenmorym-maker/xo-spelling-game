# เกม XO มาตราตัวสะกด

เกมการศึกษาที่ผสมผสานความสนุกของคลาสสิกเกม "Tic-Tac-Toe (XO)" เข้ากับทบทวนความรู้เรื่อง "มาตราตัวสะกด" ของไทย เพื่อให้ผู้เรียนได้ฝึกฝนทักษะทางภาษาไทยอย่างเพลิดเพลิน 

## 🎮 วิธีการเล่น

1. **แบ่งผู้เล่นเป็น 2 ฝ่าย** คือ ฝ่าย X และ ฝ่าย O
2. **เลือกกระดานคำถาม** ผู้สอนสามารถเลือกชุดโจทย์คำถามได้จาก 3 ชุดที่มีให้ (เลือกได้ที่แถบเมนูด้านบน)
3. **ผลัดกันเล่น** ฝ่ายที่ได้เริ่มก่อนจะเลือกคลิกการ์ด 1 ใบในตาราง 3x3 เพื่อเปิดดูคำถาม
4. **ตอบคำถาม** ผู้เล่นจะต้องตอบคำถามเรื่องมาตราตัวสะกดให้ถูกต้อง:
   - **ถ้าตอบถูก:** จะได้รับสิทธิ์ยึดช่องนั้น และเปลี่ยนการ์ดเป็นสัญลักษณ์ของทีมตัวเอง (X หรือ O)
   - **ถ้าตอบผิด:** จะหมดสิทธิ์ในตานั้น และต้องคว่ำการ์ดลง หรืออาจให้ฝ่ายตรงข้ามเป็นผู้ตอบแทน (ตามกติกาที่ตกลงกัน)
5. **หาผู้ชนะ** ฝ่ายใดที่สามารถเรียงสัญลักษณ์ของตัวเองติดกัน 3 ช่องได้ก่อน (ไม่ว่าจะเป็นแนวนอน แนวตั้ง หรือแนวทแยง) จะเป็น **ผู้ชนะ!**
